# 📘 Dissolution Manuscript: 

This repository contains the code used in the manuscript titled **"A comparison of new and established foraminiferal dissolution proxies in tropical Indian Ocean deep-sea sediments"**. It is published in the AGU journal : **Paleoceanography and Paleoclimatology**. The manuscript can be found in Chapter 4 of my thesis.

---

## 📂 Repository Structure

- **Jupyter Notebooks**
  - `dissolution_manuscript.ipynb`: Contains Python-based analyses and visualizations.

- **R Scripts**
  - `dissolution_manuscript.R`: R-based scripts for generating figures and statistical analyses.
  
- **Data Files**
  - `dissolution_indices.csv` : can be downloaded here: https://www.seanoe.org/data/00904/101616/, - `foram_frag_morphometry.csv` : can be downloaded here: https://www.seanoe.org/data/00750/86211/, 

- **Other Files**
  - `README.md`: This file.

---

## 🔍 Key Analyses and Figures

### Python Analyses
- **Dissolution Indices**: Analysis of dissolution indices using `foram_frag_morphometry.csv`.
- **Visualization**: Generation of plots and figures using libraries like `matplotlib` and `seaborn`.

### R Analyses
- **Figure 3a**: Joy plot for Mozambique Channel planktonic foraminifera.
- **Figure 3b**: Joy plot for Mozambique Channel fragments.
- **Figure S1a**: Rain cloud plot for MD96-2049.
- **Figure S1b**: Rain cloud plot for MD96-2066.

## 🚀 Getting Started

### Cloning the Repository
```bash
# Clone the repository
git clone https://github.com/your-username/code-for-manuscript-3.git
cd code-for-manuscript-3
```

### Running the Notebooks
1. Open `dissolution_manuscript.ipynb` in Jupyter Notebook or JupyterLab.
2. Ensure all required Python libraries are installed.
3. Run the cells sequentially to reproduce the analyses.

### Running the R Scripts
1. Open `dissolution_manuscript.R` in RStudio.
2. Install the required R packages if not already installed.
3. Run the script to generate the figures.
